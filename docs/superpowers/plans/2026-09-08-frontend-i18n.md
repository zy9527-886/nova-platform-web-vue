# Nova Platform Web Frontend Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add immediately switchable and persisted Simplified Chinese, Traditional Chinese, English, and Swahili translations for all fixed frontend UI copy.

**Architecture:** `vue-i18n` owns business copy while Pinia owns the persisted locale preference. The root Ant Design Vue config provider and Day.js derive their locale from the same state; routes and tabs store translation keys instead of rendered text so existing UI updates without reload.

**Tech Stack:** Vue 3.4, TypeScript 5.3, Pinia 2, Vue Router 4, Ant Design Vue 4, Day.js, vue-i18n, Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-08-frontend-i18n-design.md`

## Global Constraints

- Supported locale codes are exactly `zh-CN`, `zh-TW`, `en`, and `sw`.
- Runtime fallback locale is `zh-CN`.
- Backend business values such as `menuNm`, role names, and user names remain unchanged.
- Language selection is immediate and persists through the existing `Storage` utility.
- No backend schema or API changes are part of this plan.
- Preserve unrelated existing worktree changes in `package.json`, `pnpm-lock.yaml`, and feature files.
